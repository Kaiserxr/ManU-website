# Manchester United Fan Website

A fan-made website about Manchester United: club news, the latest kits, and profiles of the first-team squad.

**Live site:** https://kaiserxr.github.io/ManU-website/

## Pages

- **Home** (`index.html`): news, the new shirts from the United store, and players away at AFCON
- **Attackers** (`Attackers.html`): Sesko, Cunha, Mbeumo
- **Midfielders** (`Midfielders.html`): Bruno, Casemiro, Amad, Dalot, Mount, Ugarte
- **Defenders** (`Defenders.html`): Lisandro, Shaw, Yoro

Click a player's picture to open their profile page.

## Built with

- HTML
- CSS (`design_body.css`, shared by every page)
- Google Fonts (Montserrat, Roboto)

## Project structure

```
ManU-website/
├── index.html              # Home page
├── Attackers.html          # Position pages
├── Midfielders.html
├── Defenders.html
├── Bruno.html, Sesko.html… # One profile page per player
├── design_body.css         # Styles for the whole site
├── Manchester_United_FC_crest.png
└── images/
    ├── News/               # Home page news images
    ├── ads/                # Sponsor banners
    ├── forwards/
    ├── midfielders/
    └── defenders/
```

## Running it locally

Download the repo and open `index.html` in your browser. There's nothing to install.

## Hosting

The site is hosted on GitHub Pages from the `main` branch. Every push to `main` updates the live site within a minute or two.
